🐾 Panjeyar

An interactive pet-care companion — diagnose symptoms, browse a breed atlas, get a personalized breed recommendation, test your knowledge, and use handy tools. Fully bilingual (Persian/English) with light and dark mode.

✨ Features
🩺 Diagnosis Assistant — pick the symptoms you're seeing, get initial guidance (always pointing to a vet for anything serious)
🐾 Breed Atlas — 8 dog and cat breeds popular in Iranian homes, each with temperament, grooming needs, ideal living space, lifespan, and common issues
❤️ Buddy Finder — a step-by-step wizard that asks about your available time, living space, and dog/cat preference, then sorts breeds into Best Matches, Good Options, and Not Recommended — each with real, data-backed reasoning
🎯 Paw Detective — an 8-question, scenario-based knowledge quiz
🍽️ Tools — a daily food-portion calculator based on species, weight, and activity level
🆘 Emergency Help — quick first-aid guidance for urgent situations, always pointing to a vet
🛍️ Shopping Guide — practical tips before buying supplies or adopting
🌐 Fully bilingual — one-click language switch that translates the entire UI
🌗 Light / dark mode
📱 Sidebar navigation on desktop, bottom nav on mobile
